# 演示录制脚本（GIF / 短视频）

> **取材口径（2026-10-14 定）：真在线调用。**
> 录的是**真实终端**的真实运行——不摆拍、不预置字幕、不用合成动画冒充录屏。
> 素材必须落在 `docs/demo/` 的真实留档上（见 `docs/demo/README.md`）。

## 一、合规底线（先读这一节）

| 项 | 要求 |
|---|---|
| **Token** | **绝不出现在画面里**。录制前把 Token 写进 `~/.workbuddy/mcp.json` 或环境变量，**命令行里不回显**；若必须在命令行出现，则**先遮挡再录**。 |
| **门店信息** | 门店名与门店码是公开数据，可入画。 |
| **价格与营养** | 必须显示为**程序原样输出**（含「官方计价已核实」或「未核实实付」字样），不额外手写数字。 |
| **下单** | 画面须保留 `⛔ 本版本不能下单` 一行——这是诚实的正面信息，不是减分项。 |
| **不做假** | 不加速成「秒出结果」而掩盖真实耗时；不剪辑成「永远成功」。若中途报限流（业务码 508），**如实保留或重录**，不假装没发生。 |

## 二、录制前置（约 2 分钟准备）

1. **终端**：浅色主题、字号调大（≥16pt）、窗口约 **100×30** 字符，清屏后再开录；背景干净。
2. **Token**：确认已配好（跑一次 `node src/cli.ts --city 重庆市 --keyword 观音桥 --budget 35` 能出结果即可）。
3. **预热一次**：正式录之前**先跑一遍**（同一命令），确认网络与配额正常、无 508 限流；正式录时再用**清屏后的第二次**。
4. **留档**：正式那次运行**重定向存一份**到 `docs/demo/`，命名 `online-<YYYYMMDD>-<HHMMSS>-<要点>.txt`。

> **第 3 幕是本片的重点**：它同时展示三件事——① 套餐**能被展开**并取到官方营养；
> ② 替换**只在官方允许范围内**生效；③ 换一个组件，**营养与价格跟着重算**（而不是只换个名字）。
>

> `docs/DECISION_NOTES.md`「10-16 追加 · O3 结案」。

### ✅ 「套餐为何不进前三」的成因**已查明**（2026-10-16 结案，O3 关闭）

10-14 时套餐在 ¥35 预算下进不了前三，曾列为开放项 O3。10-16 复查，**证据齐备，结论如下**：

- **不是排除、不是降级**：在线 41 个套餐中 **26 个为 B 级**（可用）；以 `NON_MEAL_RE` 复算套餐名**命中 0**；
  38 个可比套餐里 **37 个菜单价与在线价完全一致**。
- **真正原因**：套餐的官方实付价多集中在 **¥32–50+**（中位 **¥38.00**），家常预算下多被挤出预算内；
  而单品的「蛋白/元」效率更高（那么大鸡排 ¥14.50 / 24g ≈ **1.66 g/元**，套餐多在 0.7–0.9 g/元）。
  故 ¥35 下前三皆为单品——**这是排序结果，不是缺陷**。
- **决定性证据**：`--budget 80 --min-protein 35` 的在线运行**首选即套餐**
  （「培根安格斯厚牛堡三件套」¥50.50，官方计价已核实）——
  留档 `docs/demo/online-20261016-103614-budget80-protein35.txt`。

完整推导与反例排查见 `docs/DECISION_NOTES.md`「10-16 追加 · O3 结案」。

### ✅ 「更换饮料 → 重算」**已可呈现**（2026-10-16 打通，O5 结案）

此前 `--variant` 只见顶层菜单项、够不到套餐内部轮次（留档 `...103621-...-variant-colalarge.txt`
与 `...103614-...txt` **逐字相同**，即当时现象的证据）。**现已接通**：新增 `--swap`，
并把替换请求从 CLI 一路透传到 `decompose`（分析层的 `substitutions` 原先传的是空数组）。
**留档保留不改**——它们是「当时确实如此」的记录；替换前后对照见 `...105347-...txt` 与
`...105353-...-swap-sugarfree-coke.txt`。

**录制时可照念的要点**：
1. 换的是**官方允许范围内**的选项——越界会被拒绝并回列可用项（可现场演示一次失败，很能说明态度）；
2. 换了饮料之后，**热量与碳水跟着变**（实测 1143→996 kcal、117→82 g），价格与蛋白不变（无糖可乐同价）；
3. 末尾「【替换请求】」块会写清**换了多少个套餐**——本店套餐共用同一套轮次命名，故一次常命中多个。

> **轮次名不唯一时不会被糊弄**：如同一套餐有两个「小食」轮次，工具**拒绝自作主张**，
> 要求改用 `小食#2`。若想在视频里体现这一点，可加一句旁白。

## 四、产出规范

- 格式：**GIF**（15–25 秒，≤5 MB，宽度 ≥960px，循环播放）；若时长不足，可另出 MP4。
- 命名：`docs/demo/mcmeal-compass-demo-<YYYYMMDD>.gif`（**ASCII 文件名**，避免跨平台解压乱码）。
- 画面内标注：一句「**演示数据取自 <日期> 真实调用，门店与价格会随时间变化**」。
- 入库时同目录留一份**当次运行的文本留档**，并在 `docs/demo/README.md` 的清单表中登记（含 SHA-256）。
